# ARIA refractive index sources

mieEODG bundles a copy of the Aerosol Refractive Index Archive (ARIA),
compiled by Don Grainger, Dan Peters, Lieven Clarisse and Hervé Herbin at the
Earth Observation Data Group, University of Oxford:
<https://eodg.atm.ox.ac.uk/ARIA/>.

ARIA asks users to acknowledge the source publications. **Cite the study below
for every material you use**; the same reference is in each `.ri` file
(`#REFERENCE`, `#DOI`) and on the parsed object (`ri.reference`). Entries
marked *via HITRAN* were compiled there first; cite also
Massie, S. T. and Hervig, M. (2013), HITRAN 2012 refractive indices,
JQSRT 130, 373-380, doi:[10.1016/j.jqsrt.2013.06.022](https://doi.org/10.1016/j.jqsrt.2013.06.022).
